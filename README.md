# Personal website
1. Sign in to GitHub and create a public repository named `soroushpakzad.github.io`.
2. Upload index.html and .nojekyll to its root and commit to main.
3. Open Settings > Pages; choose Deploy from a branch, main, / (root), and Save.
4. Visit https://soroushpakzad.github.io/ once deployment completes.

Review all biographical details and publication titles before publishing. Add your preferred public email, LinkedIn, Google Scholar and CV links. The profile image uses your public GitHub avatar. To use a local portrait, upload profile.jpg and replace the image src in index.html with profile.jpg.
