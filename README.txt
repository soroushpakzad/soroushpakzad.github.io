# Soroush Pakzad academic website

Files:
- `index.html` — main website
- `styles.css` — styling

## Replace the current GitHub Pages site

1. Open your repository: `soroushpakzad/soroushpakzad.github.io`.
2. Back up the existing `index.html` and `styles.css` first.
3. Upload the new `index.html` and `styles.css` to the repository root.
4. Choose **Commit changes**.
5. Wait a few minutes for GitHub Pages to rebuild.
6. Open `https://soroushpakzad.github.io/`.

The website is plain HTML/CSS/JavaScript and does not require a build system.

## Important
The publication list was assembled from your publicly available ResearchGate/LinkedIn/publication records. Before using the site as your definitive academic CV, check the publication list against your Google Scholar profile and add any missing papers, preprints, datasets, projects, awards, or current affiliation.

The contact form from the old template was removed because it relied on Netlify Forms, while this site is hosted on GitHub Pages. The new site uses direct email/contact links instead.
